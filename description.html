Sort messages, then summarize or reply. AI Sorting tags messages as Important, Newsletters, or Social. Rules on this computer handle the obvious ones. Connect ChatGPT, OpenRouter, Gemini, or Grok when you want a summary, a draft reply, or a decision the rules cannot make. Key features:
  • Tags appear in the message list and in the quick filter.
  • New inbox mail can be tagged as it arrives.
  • Summarize an open thread, or draft a reply, in English.
  • The API key stays in this profile. A message is sent to the provider only when the model is called.
Installation:
  1. In Thunderbird, open the menu and choose Add-ons and Themes.
  2. Click the gear icon and choose Install Add-on From File…, then select the .xpi. Or type AI Sorting in the search field, open this add-on, and choose Add to Thunderbird.
  3. When Thunderbird asks for access, choose Add.
  4. Open the add-on settings and add an API key before using summaries, drafts, or model sorting.
This add-on needs Thunderbird 128 or newer. Settings Open Settings from the AI Sorting toolbar button, or from the add-on card in Add-ons and Themes.
  • Provider — ChatGPT, OpenRouter, Gemini, or Grok.
  • API key — the key for that provider.
  • Model — leave this blank to use the provider’s default model, or type a model name.
  • Sort new inbox mail — tag messages as they arrive in the inbox.
  • Ask the model when rules are unsure — sends the sender, the subject, and the beginning of the message. At most 40 messages an hour.
Choose Save, then Test connection. The status line confirms that the provider answered. Sort a folder Click the AI Sorting button on the mail toolbar.
  • Sort messages sorts the selected messages when more than one is selected. Otherwise it sorts the current page of the open folder, up to 50 messages.
  • The popup shows how many messages were marked Important, Newsletters, Social, and Other.
  • Settings opens the options page.
Important uses the Important tag already in Thunderbird. Newsletters and Social are added only when those names are not already there. Other means the message was classified and left without one of those tags. Messages the rules could not classify stay untagged when the model is off, the API key is missing, or the hourly limit is reached. An open message Open a message and click Summarize and reply on the message toolbar.
  • The popup shows the current tag, if the message has one.
  • Sort again classifies this message once more and notes whether the rules or the model decided.
  • Summarize thread writes three short sections in English: Decisions, Open questions, and Next steps.
  • Draft reply opens a reply window with an English draft.
While writing In a compose window, click Draft with AI.
  • Type an instruction, such as “A short, friendly reply”, or leave it empty.
  • Make it shorter tightens the current draft. Politely decline writes a brief refusal.
  • Insert into draft places the text in the message you are writing.
Replies and summaries are written in English. How a message is tagged
  • Newsletters — mailing lists, bulk mail, and addresses such as noreply.
  • Social — mail from social networks.
  • Important — the sender is in your address book, or the message is addressed to one of your accounts.
  • Anything else waits for the model, when that option is on.
